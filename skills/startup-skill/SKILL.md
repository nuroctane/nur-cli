# Startup skill pack

Use the installed workflows from [ferdinandobons/startup-skill](https://github.com/ferdinandobons/startup-skill), pinned in `skills/upstream-lock.json`.

Select and read the matching sibling skill before doing the work:

- `../startup-design/SKILL.md`: validate an idea, map assumptions, research demand, plan experiments, and decide what to build.
- `../startup-competitors/SKILL.md`: research competitors, alternatives, pricing, and differentiation.
- `../startup-positioning/SKILL.md`: define audience, category, value proposition, and positioning.
- `../startup-pitch/SKILL.md`: develop a pitch using the startup's evidence and positioning.

If the request spans several workflows, start with validation and carry its evidence into competitors, positioning, then the pitch. Use the user's existing context to choose the entry point. Keep unsupported market claims explicit and verify live facts from primary sources.
