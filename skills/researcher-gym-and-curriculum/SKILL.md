# Researcher gym and curriculum

Full reading list: `sc-research/references/gym.md`.

## Session behavior

When the user wants to "learn", "practice", or "become a researcher":

1. Pick the next gym item they have not finished (ask; default Ethernaut then DVD v4).
2. Implement in Foundry. No Remix-only solutions.
3. After each solve: SWC id, Solodit analog, one invariant.
4. Do not spoil CTF flags if they asked to try first - give hints, then the test.

## After the gym

In-scope C4/Cantina/Sherlock as a warden, then Immunefi programs with a published policy. Load `contest-and-bounty-reporting`.
